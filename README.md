# Image to ASCII converter
 ### - Variable size and quality
 ### - Customizable fonts
 ### - Supports alpha channels

# Quick start

## Windows
```console
.\build.bat
cd .\build
.\img2ascii <image_filename> [--quality 1..100] [--ascii-set 1..3]
```

## Linux
```console
./build.sh
cd ./build
./img2ascii <image_filename> [--quality 1..100] [--ascii-set 1..3]
```
